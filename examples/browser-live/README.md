# Live Transcription (Browser)

This example demonstrates how to transcribe a live audio stream in the browser using the Deepgram JS SDK.

## Setup

1.  Just copy the code and host the html using liveserver

2.  Open your browser and give the api key (get it from deepgram: https://deepgram.com/)

3. After giving the api, click on start it will show transcript in the page itself.
